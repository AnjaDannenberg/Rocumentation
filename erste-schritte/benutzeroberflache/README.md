### Drawing

Vorteil:

* Drawings können im Editor angepasst werden

Nachteil:

* Drawings haben keinen Alt-Text.
* Drawings nehmen immer die gesamte Blockbreite ein. Dabei kann das Bild pixelig werden (Workaround mit weißem Hintergrund möglich). Bei einem Image kann die Größe hingegen grob angepasst werden.
* Änderungen werden nicht immer sichtbar. Ein Neuladen der Seite kann helfen.
